# TWSM そらあそびパーク

株式会社TWSM-JAPAN（ドローンスクール 養父本校・神戸三宮校）公式ミニゲームサイト。
20〜30代女性・母親世代がスマホでつい遊んでしまう、片手操作のミニゲーム3本＋エントランス。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | エントランス（ハブ）。時間帯で変わる空・タップ追従ドローン・3ゲームへの導線・そらマイル/バッジ・スクールCTA |
| `delivery.html` | game1 **そらのおとどけ便** — ホールドで上昇/離すと下降の浮遊アクション。コンボ・フィーバー・図鑑24種 |
| `landing.html` | game2 **ぴたっとランディング** — 2タップ精密着陸。全12ステージ×★3、PERFECT演出、デイリーぴたっ率 |
| `diary.html` | game3 **ドローンおしごとダイアリー** — 7日間おしごとシム＋学科クイズ＋8タイプ適性診断。`?mode=quick`で3分クイック診断 |

## 技術

- 各ファイル**単一HTML完結**（HTML+CSS+JSインライン）。外部CDN・ライブラリ依存なし
- Canvas 2D / requestAnimationFrame（deltaTime方式）/ WebAudio合成SE / localStorage セーブ
- スマホ縦画面（9:16基準）・片手/親指1本操作・DPR対応・セーフエリア対応
- ビジュアル: ChatGPT生成画像100枚を組み込み済み（`assets/opt/*.webp`・軽量化済み計約4.5MB）。未生成分はコード描画のフォールバックで表示。原本PNGは `assets/`（公開時は `opt/` のみで可）

## 開く / 公開する

- ローカル: `index.html` をブラウザで開くだけ（スマホ実機での確認推奨）
- 公開: フォルダごと静的ホスティング（例: Cloudflare Pages）に置く。kovecと同じ `.../games/twsm/` 構成

## 進捗の保存

`twsm_meta`（マイル・バッジ）/ `twsm_g1..g3`（各ゲーム）/ `twsm_settings`（音）を localStorage に保存。ゲーム間でそらマイル・クロスアンロックを共有。
